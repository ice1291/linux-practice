 # Linux运维练习项目

  这个项目记录我学习Linux运维技术的练习过程。

  ## 项目结构
  - `basic-commands/` - 基础Linux命令练习
  - `system-admin/` - 系统管理命令练习
  - `troubleshooting/` - 故障排除练习
  - `ansible/` - Ansible自动化部署练习
  - `nginx/` - Nginx配置练习

  ## 如何使用
  1. 克隆此仓库到本地
  2. 按照目录进行练习
  3. 记录命令和结果
  4. 定期提交到GitHub

  ## 学习目标
  - 掌握Linux系统管理
  - 学习自动化运维工具
  - 提升故障排查能力
