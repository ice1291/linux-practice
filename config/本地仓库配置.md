# 本地仓库配置（挂载iso），仓库是软件包的集合，在本地直接使用dnf下载的都是仓库中包含的软件包

# 一.挂载iso
## 1. 创建挂载点：mkdir -p /mnt/rhel10
## 2. 开机自动挂载：echo "/dev/sro(设备) /mnt/rhel10(挂载点) iso9660(文件系统类型) defaults 0 0">> /etc/fstab
## 3. 验证： mount -a ；ls /mnt/rhel10(看到挂载点目录中有APPStream和BaseOs即可）

# 二.配置.repo文件
## 1. 备份原有repo（避免冲突）：mkdir -p /etc/yum.repos.d/backup ; mv /etc/yum.repos.d/*.repo /etc/yum.repos.d/backup
## 2. 创建本地仓库文件：（以.repo结尾) vim /etc/yum.repos.d/rhel10_local.repo
## 3. 写入内容：
[BaseOS] </br>
name=rhel 10 BaseOS local </br>
baseurl=file:///mnt/rhel10/BaseOS </br>
enabled=1 </br>
gpgcheck=0 </br>

[AppStream] </br>
name= rhel 10 AppStream local </br>
baseurl=file:///mnt/rhel10/AppStream  </br>
enabled=1 </br>
gpgcheck=0 </br>

/etc/dnf/dnf.conf里面有定义仓库目录的参数：reposdir=路径（修改后使用dnf下载将从该路径中寻找.repo仓库文件）
