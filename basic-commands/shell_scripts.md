# shell脚本编写
##脚本首行必须通过Shebang指定解释器（#!/bin/bash)

赋予执行权限后路径执行：chmod +x script.sh && ./script.sh。</br>
解释器显式调用：bash script.sh（无需权限，新建子Shell）。</br>
当前环境加载配置：source script.sh 或 . script.sh（变量保留在当前Shell）</br>

$0:脚本文件名；</br>
$1..$9:第n个传入的参数；</br>
$#:传给脚本参数的总数；</br>
$$:当前PID</br>
$@：传入的所有参数；</br>
$?：上一条命令执行后退出的状态码（0：成功，非0：失败）</br>
$变量：最基础取变量值,必须使用双引号包裹变量**"$变量"** </br>
$((算式))：进行数学计算</br>
$(命令）:取命令的执行结果</br>

!：取反；</br>
### 数值比较
-ge(greater or equal)大于等于；</br>
-gt(greater than)大于；</br>
-lt(less than)小于；</br>
-le(less or equal)小于等于；</br>
-eq(equal)等于；</br>
-ne(not equal)不等于；</br>
### 字符串比较
=/==：判断两个字符串是否相等，在"[]"使用=，"[[]]"使用==</br>
!=:判断两字符串是否不等</br>
-z string:判断字符串是否为空，为空，返回真 </br>
-n string:判断字符串是否非空,非空，返回真</br>
>:判断左边字符串按字典顺序是否大于右边</br>
<:判断左侧字符串是否小于右边</br>
**在单中括号 [ ] 中使用 < 和 > 时，必须加反斜杠转义（\< 和 \>），否则会被 Shell 误认为是重定向符号；而在双中括号 [[ ]] 中则可以直接使用。**
**=~：判断左侧字符串是否匹配右侧的扩展正则表达式。如果匹配成功，则返回真。这在日志分析和复杂文本提取中非常实用。仅 [[ ]] 支持**
### 文件测试
-f 文件路径:检测是否为文件；</br>
-d 目录路径：检测是否为目录；</br>
-e 路径：存在性判断；</br>
-x 脚本文件：检测是否为可执行属性</br>
-s 文件：判断文件大小非0 </br>
## read命令：read [选项] [变量名...]
 变量赋值与分割规则（IFS）
read 命令默认使用 IFS（内部字段分隔符，默认为空格、制表符和换行符）来分割输入行：
多变量赋值：如果指定了多个变量（如 read var1 var2），输入内容会被分割并依次赋值。
多余字段处理：如果输入的字段数多于变量数，剩余的所有字段（包含它们之间的分隔符）会全部赋值给最后一个变量。
变量置空：如果输入的字段数少于变量数，多余的变量会被赋值为空字符串。</br>

-p "提示信息" 变量名 ：在读取输入前，向用户显示一段提示文本</br>
-s :静默模式，输出的内容不会再屏幕上回显，常用与脚本中读取密码等敏感信息</br>
**交互式密码输入**</br>
read -s -p "请输入您的密码：" password</br>
echo "" # 换行，因为静默模式不会自动换行</br>
echo "密码已接收" </br>

-n 字符数：读取指定数量的字符后自动结束，无需按回车（常用于Y/N）</br>
-t 秒数:设置未输入超时时间 </br>
**带超时的确认提示**</br>
read -n 1 -t 5 -p "是否继续？(y/n): " choice </br>
if [ -z "$choice" ]; then </br>
    echo "输入超时，默认取消。"</br>
else</br>
    echo "您的选择是: $choice" </br>
fi</br>

-a 数组名：将输入的内容按默认分隔符（空格）分割，并存储为索引数组</br>
-r:禁用\的转义功能，保留用户输入的原始状态，必加！ </br>
