  # Linux用户管理命令

  ## 用户操作
  1. `useradd username` - 创建新用户
     - 示例：`sudo useradd testuser`
     - 说明：需要root权限

  2. `userdel username` - 删除用户
     - 示例：`sudo userdel testuser`

  3. `passwd username` - 修改用户密码
     - 示例：`sudo passwd testuser`

  4. `su username` - 切换用户
     - 示例：`su testuser`

  5. `sudo command` - 以root权限执行命令
     - 示例：`sudo apt update`
